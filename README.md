# 🛸 EKAKI VILLA: CLASSIFIED ARCHIVE

> *"THEY ARE HERE..."*

An immersive, interactive web experience exploring the mysterious lore of **ACV Studios** and the **Ekaki Villa** conspiracy. This project serves as a digital archive for the unexplained phenomena surrounding the channel.

## 📂 CLASSIFIED DATA
This website is built as a "found footage" style interface, requiring users to interact with various terminals and cryptographic puzzles to uncover the truth.

### 🕵️‍♂️ Key Features
-   **Signal Interception**: A fully functional frequency tuner to decrypt the landing signal.
-   **The Conspiracy Board**: An interactive digital corkboard connecting the dots between "The Dealer," "The Mission," and the "Crash Site."
-   **Optical Illusions**: Mouse-tracking flashlight effects and hidden UV ink messages.
-   **The Abduction**: An optimized frame-by-frame scroll animation (Canvas Flipbook) depicting the final moments of [REDACTED].
-   **Mobile-Ready**: Optimized with gyroscope-like pendulum physics for mobile users.
